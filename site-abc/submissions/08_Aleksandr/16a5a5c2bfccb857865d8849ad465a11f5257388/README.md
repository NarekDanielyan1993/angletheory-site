# AI Opportunity Audit: design mockup

Test task 08. Design of one page of the AI Business Systems website: AI Opportunity Audit (/services/ai-opportunity-audit/). Desktop (1440 px) and mobile (390 px) versions.

## Files

- `previews/Desktop-1440.png`: full desktop page, top to bottom
- `previews/Mobile-390.png`: full mobile page, top to bottom
- `sources/[имя файла].fig`: editable Figma source (layers, text, buttons and components are editable)
- `assets/`: images used in the design
- `fonts-and-licenses/fonts-and-licenses.md`: fonts, sources and licenses
- `responsive-and-actions/responsive-and-actions.md`: responsive behavior, design parameters, states, button and link actions

## Program

Figma (dekstop app).

To open: Figma, File, Open file (or drag the `.fig` file into Figma). The file has two page frames, `Page/Desktop-1440` and `Page/Mobile-390`, plus a `Spec/States` frame with button and link states. Typography styles and color variables are in the file.

## Dependencies

- Montserrat font. Download: https://fonts.google.com/specimen/Montserrat. Install it before opening the file, otherwise Figma will substitute the font.
- No closed external accounts or plugins are required.
